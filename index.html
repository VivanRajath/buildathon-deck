Vox Build05

The agents

Nine agents, each with one job

Vox

The Bolna voice agent. Listens, talks back, calls the builders.

Researcher

Design brief, art direction, palette, sections and real photos.

Font Knight

A real Google Fonts pairing and Lucide icons, from live catalogues.

Copywriter

Headlines, calls to action and section copy in the brief’s tone.

Architect

Builds the full page from the plan and handles redesigns.

Design Critic

Reviews every new page and fixes the worst issues.

Intent Router

Sorts each spoken edit into small, bigger or full.

Junior Dev

A fast model for small tweaks, applied as precise patches.

Senior Dev

A stronger model for new sections and layout changes.

Vox Build07

Editing by voice

Every edit goes to the right developer

Kind of editWhat you sayHandled byHow
Small“Make the heading dark green”Junior DevFast model, precise patch
Bigger“Add a testimonials section”Senior DevStronger model, patches
Full“Redesign it with a dark theme”ArchitectTop model, full rewrite

If a patch can’t be applied, the edit moves up to the next developer on its own. Cheap models do the easy work without ever risking a broken page.
