# Vox Build: Bolna Buildathon deck

The pitch deck for **Vox Build**, a voice website builder made with Bolna for the Bolna Buildathon 2026.

Live: https://vivanrajath.github.io/buildathon-deck/

Demo video: https://www.loom.com/share/fc5195a409e84af18a43ca9baddb31f4 (also embedded on slide 4)

## Controls

- Arrow keys, Space, Page Up / Page Down, or the buttons in the corner
- Click the right side of a slide to go forward, the left side to go back
- Swipe on touch screens
- `F` for full screen
- Link to a slide with `#n`, for example `#6` for the agents

It is a single `index.html` with no build step.
